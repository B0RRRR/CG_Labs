# Лабораторная работа №1: Основы 3D-графики

**Вариант: правильный октаэдр**

Цель — построить простой 3D-объект, спроецировать его на плоскость экрана и
научиться работать с матрицами проекций и аффинных преобразований.
Программа работает в реальном времени, проекция и преобразования меняются на ходу.

## Сборка и запуск

Из корня репозитория:

```bash
cmake --preset debug -DLAB=1
cmake --build build-debug --parallel
./build-debug/vulkan-starter-app
```

## Отчёт

```bash
cd labs/lab1
xelatex report.tex && xelatex report.tex
```


## Что реализовано

| | Задание | Где смотреть |
| --- | --- | --- |
| Основное | Правильный октаэдр | `octahedron_positions`, `octahedron_indices` |
| 1 | Переключение перспективной и ортографической проекции | раздел **Projection**, `math::perspective` / `math::orthographic` |
| 2 | Изменение позиции, поворота и растяжения | раздел **Transform**, `model_matrix` в `update()` |
| 3 | Движение по сложной траектории, пауза и параметры | раздел **Animation**, `animationOffset()` |
| 4 | Изменение цвета фигуры (`ColorEdit`) | раздел **Color** |
| 5 | Процедурные цвета вершин, умножаемые на выбранный цвет | `createMesh()` и `octahedron.vert` |


## Управление

Всё в окне **Lab 1 - Octahedron**:

- **Projection** — тип проекции, угол обзора или высота видимой области, удаление камеры.
  Разница проекций заметнее всего, если увеличить фигуру и подвинуть её от центра.
- **Transform** — позиция, поворот и масштаб по трём осям, кнопка сброса.
- **Animation** — Play/Pause, рестарт, скорость, радиус и высота траектории,
  скорость собственного вращения.
- **Color** — выбор цвета и переключение процедурных цветов вершин.
