# Лабораторная работа №3: Текстурирование

**Объект: правильный октаэдр** (из первой работы) в комнате из пола и трёх стен,
освещение по модели Блинна-Фонга из второй работы.

Выполнено базовое задание и дополнительные задания 1–2 (на оценку 4).

## Сборка и запуск

Из корня репозитория:

```bash
cmake --preset debug -DLAB=3
cmake --build build-debug --parallel
./build-debug/vulkan-starter-app
```

Программу нужно запускать из корня репозитория: шейдеры читаются из `shaders/`,
текстуры — из `labs/lab3/textures/`.

## Отчёт

```bash
cd labs/lab3
xelatex report.tex && xelatex report.tex
```

## Что реализовано

| | Задание | Где в коде |
| --- | --- | --- |
| База | Изображения загружаются из PNG-файлов библиотекой stb_image | `loadTexture` |
| База | Текстура вместо сплошного цвета в качестве альбедо | `albedo` в `textured.frag` |
| База | Текстурные координаты в вершинах, генерируются процедурно | `buildOctahedron`, `buildQuad` |
| База | Один динамический uniform-буфер со свойствами всех моделей, сдвиг — при привязке набора | `uploadFrameData`, `render` |
| База | Вершины и индексы в VRAM, копирование из staging-буфера командами GPU | `createDeviceBuffer`, `endUpload` |
| 1 | Шесть текстур, выбор для каждой модели из выпадающего списка, свой набор дескрипторов на текстуру | `drawTextureCombo`, `createDescriptors` |
| 2 | Анимированное сэмплирование: искажение координат, две выборки одной текстуры, модуляция цвета; включается push-константами | `animatedAlbedo` в `textured.frag`, `render` |

## Файлы

```
application.cpp         буферы в VRAM, текстуры, наборы дескрипторов, конвейер, интерфейс
math.hpp                векторы и матрицы (из первой работы)
shaders/textured.vert   перевод в мировые координаты, передача текстурных координат
shaders/textured.frag   выборка из текстуры, анимированный эффект, Блинн-Фонг
textures/               изображения текстур (PNG 512×512, бесшовные)
```
