# Лабораторная работа №2: Камера и освещение

**Объект: правильный октаэдр** (из первой работы), освещение по модели Блинна-Фонга.

Выполнено базовое задание и дополнительные задания 1–3 (на оценку 4).

## Сборка и запуск

Из корня репозитория:

```bash
cmake --preset debug -DLAB=2
cmake --build build-debug --parallel
./build-debug/vulkan-starter-app
```

## Что реализовано

| | Задание | Где в коде |
| --- | --- | --- |
| База | Камера, направленный источник, рассеянный свет, материал — всё меняется в интерфейсе | `drawInterface`, `uploadFrameData` |
| База | Нормали вершин генерируются процедурно | `buildFlatMesh` |
| База | Блинн-Фонг во фрагментном шейдере | `blinnPhong` в `lit.frag` |
| 1 | Два набора дескрипторов: сцена и модель | `createDescriptors`, `render` |
| 2 | Массив точечных источников в storage-буфере, затухание по обратным квадратам | `drawPointLights`, цикл в `lit.frag` |
| 3 | Массив прожекторов в storage-буфере, затухание и мягкие края | `drawSpotLights`, цикл в `lit.frag` |

## Файлы

```
application.cpp     буферы, наборы дескрипторов, конвейер, интерфейс
math.hpp            векторы и матрицы (из первой работы)
shaders/lit.vert    перевод вершины и нормали в мировые координаты
shaders/lit.frag    освещение по Блинну-Фонгу
```
